Library Management System

Description: 
This project is a Library Management System written in Java. The program allows users to manage books and borrowers and perform basic library transactions such as borrowing and returning books. The goal of the project is to practice object-oriented programming, collections, and file handling while building a functional application.

Features: 
The system allows users to add, edit, delete, and list books in the library. It also supports borrower management, including registering and updating borrower information. Borrowers can check out available books and return them when finished. The program also includes search features that allow users to find books by title, author, or genre.

Technologies Used: 
The project is developed using Java (JDK 23). It uses object-oriented programming concepts such as classes and encapsulation, collections like ArrayList and HashMap to manage data, and file handling to store information about books and borrowers.

How to Run: 
Clone the repository to your computer and open the project in an IDE such as IntelliJ, Eclipse, or VS Code. Compile the project and run the Main.java file. Once the program starts, follow the menu options to manage books, borrowers, and library transactions.
